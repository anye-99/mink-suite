# Mink 妙笔批注套件 (mink-suite)

一款面向深度阅读与手写批注场景的 Obsidian 插件：独立手写笔记、PDF 全方位标注、遮盖复习、学习卡片与 AI 问答，一站式完成「读 → 画 → 批 → 复习 → 整理」的知识加工链路。

## 功能总览

### 独立手写笔记（.mink）
- 创建 `.mink` 手写文件，支持多页与页面管理
- 横线 / 方格 / 点阵 / 空白纸张模板
- 笔迹（压感模拟）、矩形、圆形、线条、箭头、文本、贴纸、图片
- 荧光笔模式、橡皮、撤销 / 重做
- 在 Markdown 中嵌入预览 `![[笔记.mink]]`（前 3 页缩略，点击打开）

### PDF 标注
- **对象标注**：在 PDF 页面任意插入文本、矩形、圆形、线条、单向箭头、双向箭头
- **文本批注**：对可选文本做高亮、下划线，附加笔记与 AI 问答
- **遮盖复习**：对选中文字或任意框选区域创建遮盖，点击显示 / 再次点击遮回，自测记忆
- **阅读导航**：目录（大纲）、书签、全文搜索、页码定位、页级出链引用框
- **截图与区域选择**：圈画页面区域，生成截图、复制回链、保存图片、OCR 识别、AI 问图
- **笔迹选择**：框选已有笔迹后复制、粘贴、删除、缩放或生成回链截图

### 书写便利贴
- 在 PDF 标注、Markdown 批注和独立手写笔记中插入可独立书写的便利贴（可拖动 / 缩放 / 编辑文字）

### 批注管理
- **批注中心**：按文档或按时间集中查看 Markdown、PDF 与手写笔记中的全部批注，支持转文字、追问 AI、生成学习卡片
- **批注导出多维表**：把所选批注、单个文档或筛选结果导出为 `.duowei` 文件
- **Markdown 原文批注侧栏**：在源文旁添加、查看、维护批注，编辑器内有批注的行显示角标

### 学习卡片
- 把文本、截图、OCR 结果或重点批注收藏为学习卡片
- 阅读页卡片抽屉：不离开当前文档即可搜索、筛选、OCR 和管理卡片

### 批注思维导图（.imap）
- 创建并打开 `.imap` 思维导图，画布支持平移 / 缩放 / 适应画布
- 节点操作：添加子节点 / 同级、编辑文字与备注、颜色、折叠子树、删除；拖拽微调位置（子树整体跟随），拖到其他节点上即改挂父级
- 自动左右分栏树布局，「整理布局」一键还原手动偏移；撤销 / 重做
- **持续采集**：批注中心（单条或勾选批量）、PDF 选中文本菜单「入图」、Markdown 命令「把选中文字加入脑图」、截图弹窗「加入脑图」
- 节点保留采集来源：一键跳回原文（PDF 页码 / .mink / Markdown），可复制来源回链；截图节点带缩略图

### AI 能力（需自行配置 OpenAI 兼容接口）
- 对选中内容 / 截图 / 笔迹提问
- AI 会话历史：搜索、置顶、重命名、继续此前会话
- 手写笔迹 AI 转文字

### 其他
- 触控输入优化（手掌误触过滤、触屏加大命中区域，适配 iPad / 触控屏）
- PDF 导出：导出包含笔迹、文本批注、对象标注、便利贴与独立笔记内容的 PDF（中文需配置 CJK 字体）
- 标准 PDF 批注互操作：导入 PDF 内置批注；导出标准批注副本，或备份后写回源 PDF

## 安装

### 方式一：BRAT（推荐，未上架商店期间的更新通道）

1. 在 Obsidian 中安装并启用社区插件 [BRAT](https://github.com/TfTHacker/obsidian42-brat)
2. 打开命令面板（Ctrl/Cmd+P）→ 运行 `BRAT: Add a beta plugin for testing`
3. 输入本仓库地址，确认安装
4. 在 设置 → 第三方插件 中启用「Mink 妙笔批注套件」

### 方式二：手动安装

1. 从 [Releases](../../releases) 页面下载 `main.js`、`manifest.json`、`styles.css` 三个文件
2. 在你的 vault 中创建 `.obsidian/plugins/mink-suite/` 目录，将三个文件放入
3. 重启 Obsidian，在 设置 → 第三方插件 中启用

## 使用说明

### 快速上手
1. 命令面板运行「新建手写笔记」创建 `.mink` 文件，用工具栏切换画笔 / 形状 / 文本 / 贴纸
2. 打开任意 PDF，页面右上角出现标注工具栏（若未出现，等待 2 秒让视图容器就绪）
3. 选中 PDF 文本后弹出快捷菜单：高亮 / 下划线 / 笔记 / 遮盖 / 问答 / 入图
4. 命令面板「打开批注中心」集中管理全部批注
5. 命令「新建思维导图」创建 `.imap`；在批注中心、PDF 选区菜单或截图弹窗中「加入脑图」，持续沉淀知识结构

### 必要配置
- **AI 功能**：设置 → Mink 妙笔批注套件 → AI，填入 OpenAI 兼容接口的 baseUrl、apiKey、模型名
- **中文 PDF 导出**：设置中指定 CJK 字体文件（.ttf/.otf）的 vault 内路径，否则中文导出为 `?`
- **OCR**：默认走 Tesseract（联网加载），也可切换为 AI 通道

### 数据存放
批注侧车、卡片、AI 历史等数据保存在 vault 内 `.mink-suite/` 目录（可在设置中修改），不改动原始 PDF 与 Markdown 文件。

## 已知限制

- PDF 标注依赖对 Obsidian 内部视图结构的探测，Obsidian 大版本更新后可能需要适配（失效时其余功能不受影响，页面会显示降级提示）
- PDF 大纲 / 全文搜索 / 标准批注导入依赖 Obsidian 内置 pdf.js 实例，不可用时相应功能降级
- OCR 依赖已配置的 AI 视觉模型接口
